# Ecosistema de Automatización IA

## Trabajo Final

Sistema de automatización desarrollado para gestionar consultas sobre concursos nodocentes de una Facultad.

El proyecto utiliza n8n como orquestador, Airtable como base de datos y un modelo de Inteligencia Artificial (Groq Llama 3.3 70B) para interpretar consultas y generar respuestas.

## Funcionalidades

- Recepción de consultas mediante Webhook.
- Simulación de consultas utilizando Postman.
- Clasificación automática de consultas simples y complejas.
- Respuestas automáticas mediante IA.
- Human in the Loop para consultas complejas.
- Registro de consultas y errores.
- Dashboard de monitoreo en Airtable.

## Tecnologías utilizadas

- n8n
- Airtable
- Groq
- Gmail
- Webhooks
- Postman
